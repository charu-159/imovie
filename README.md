# 🎬 iMovies – Movie Website

iMovies is a full-stack movie website built using the MERN stack.

### 🛠️ Technologies
- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

### ✨ Features
- User registration and login
- Movie listing and details
- REST API integration
- MongoDB database connectivity

### ⚙️ Setup
1. Install dependencies using `npm install`.
2. Configure MongoDB URI in the `.env` file.
3. Start the backend using `node server.js`.
4. Start the frontend using `npm run dev`.

### 🎯 Objective
To learn full-stack development, API integration, and database management.
